Política de Privacidad

Stickers del Tío Lalamove · Vigente desde 21 de septiembre de 2026

Resumen: la versión actual de Stickers del Tío Lalamove no requiere registro, no incorpora publicidad, no integra herramientas de analítica ni dispone de un servidor propio para recopilar o almacenar datos personales del usuario.

1. Alcance

Esta Política de Privacidad describe el tratamiento de información relacionado con el uso de la aplicación Stickers del Tío Lalamove para Android.

2. Información que recopila la aplicación

La aplicación no solicita al usuario crear una cuenta y no recopila directamente nombre, número telefónico, correo electrónico, ubicación, contactos, fotografías, identificadores publicitarios ni datos financieros.

La versión actual tampoco solicita permisos de acceso a Internet, ubicación, cámara, micrófono, contactos ni almacenamiento externo. No se incluyen SDK de publicidad, medición de audiencia o analítica de terceros.

3. Funcionamiento local

Los stickers y recursos necesarios para el funcionamiento de la aplicación se incluyen dentro del propio APK. Cuando el usuario utiliza la función para compartir un sticker, Android puede crear o exponer temporalmente un archivo en el espacio de caché de la aplicación y conceder acceso temporal únicamente a la aplicación que el usuario seleccione para recibir dicho contenido. La aplicación no utiliza ese proceso para enviar información a servidores propios.

4. Integración con WhatsApp y otras aplicaciones

La aplicación permite agregar un paquete de stickers a WhatsApp y utilizar el selector de Android para compartir contenido con otras aplicaciones instaladas. Cuando el usuario decide abrir, compartir o transferir contenido hacia una aplicación de terceros, el tratamiento posterior de la información queda sujeto a las políticas y condiciones de ese tercero.

5. Enlaces externos

La aplicación puede abrir enlaces externos, por ejemplo la ficha de WhatsApp en Google Play o el sitio web del editor. Al abandonar la aplicación, se aplican las políticas de privacidad del sitio o servicio visitado.

6. Conservación de datos

La aplicación no mantiene una base de datos remota de usuarios ni almacena datos personales en servidores del desarrollador. Los archivos temporales creados para funciones de compartición pueden permanecer durante un tiempo limitado en la caché local del dispositivo y pueden ser eliminados por Android o al limpiar los datos de la aplicación.

7. Menores de edad

La aplicación no está diseñada para recopilar datos personales de menores de edad y, conforme a su funcionamiento actual, no solicita ni almacena datos personales de sus usuarios.

8. Seguridad

Se procura limitar el tratamiento de información al mínimo necesario para ofrecer las funciones de visualización, compartición e incorporación de stickers. No obstante, la seguridad de aplicaciones o servicios de terceros que el usuario decida utilizar se rige por sus propios mecanismos y políticas.

9. Cambios a esta política

Si una versión futura incorpora nuevas funciones que impliquen recopilación o tratamiento de datos personales, esta Política de Privacidad deberá actualizarse antes de distribuir esa versión.
